# wikitransgeo（WikiTranslate Lite - Geography）

[wikitranslate](https://github.com/Arbeit2025/wikitranslate) の試作版で、地理（村・集落・町・川・山・島・湖）に絞って、日本語版 Wikipedia がない記事を探します。

## 公開ページ

https://arbeit2025.github.io/wikitransgeo/

ブラウザだけで動作する単一 HTML のツールで、インストールは不要です。
